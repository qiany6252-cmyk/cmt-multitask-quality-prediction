# cmt-multitask-quality-prediction
面向颗粒增强金属基复合材料CMT沉积过程的多任务质量预测，提供实验视频、CNN-LSTM模型代码及预训练权重，用于焊道高度、宽度和颗粒面积占比的预测。

# CMT沉积焊道几何与颗粒面积占比的多任务预测

本仓库提供颗粒增强金属基复合材料CMT沉积研究的实验视频、多任务预测模型代码及预训练权重。

## 公开资源

- 实验视频：展示不同实验条件下的沉积过程。
- 模型代码：包含网络结构和训练程序。
- 预训练权重：提供与公开代码版本对应的模型检查点。

## 环境与使用

运行环境：
- Python：3.10.18
- PyTorch：2.1.0
- CUDA：12.1
- GPU：NVIDIA GeForce RTX 3050 Laptop GPU（4 GB）
